Configuration de l'instance Firebase Lumesys

Connexion sécurisée directe depuis le navigateur sans exposer de clé privée côté serveur

Structure Firestore requise :

  • Collection existante : utilisateurs/{userId}
  • Collection de messagerie : conversations/{conversationId}
  • Sous-collection : conversations/{id}/messages/{messageId}

Compatibilité GitHub Pages :

Pour déployer sur GitHub Pages, poussez ce dépôt sur GitHub, activez Pages dans les réglages (branche main, dossier root ou dist), et accédez à votre URL gratuite https://MON-COMPTE.github.io/MON-REPOSITORY/.

Configuration Firebase Lumesys

Vos clés sont stockées localement dans votre navigateur et transmises exclusivement aux serveurs officiels de Google Firebase.
